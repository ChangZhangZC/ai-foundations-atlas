## 二、单选题（每题 4 分）

### 单选 1：C++ 运行结果

**题目：** 以下 C++ 代码的运行结果是什么？

```cpp
#include <iostream>
using namespace std;

int main() {
    int array[] = {10, 20, 30};
    cout << -2[array-1];
    return 0;
}
```

- A. -20
- B. -10
- C. 编译出错
- D. -30

**参考答案：A（-20）**

**考点：** 在 C/C++ 中，`a[b]` 等价于 `*(a + b)`。因此 `2[array - 1]` 等价于 `*(2 + array - 1)`，取到 `array[1] = 20`，前面的负号使结果为 `-20`。

### 单选 2：TCP 三次握手

**题目：** 客户机 A 向服务器 B 发起 TCP 连接请求，已知第三次握手时的确认报文段中 `ack = 2048, seq = 1024`，问客户机 A 向服务器 B 发送的连接请求报文段为（ ）。

- A. `SYN = 1, ACK = 1, seq = 2047, ack = 1024`
- B. `SYN = 1, seq = 1024`
- C. `SYN = 1, ACK = 1, seq = 2047, ack = 1023`
- D. `SYN = 1, seq = 1023`

**参考答案：D**

**考点：** SYN 占用一个序列号。第三次握手的 `seq = 1024`，因此第一次握手客户端 SYN 的初始序列号是 `1023`。

### 单选 3：Agent 的短期状态、长期记忆与知识库

**题目：** 用户委托 Agent 安排下周的出差。当前会话已确定本次行程为“周二出发、周五返回”，用户还明确表示“以后出差优先选择高铁”；Agent 需要依据企业知识库中的报销规则核对方案。为了让当前任务和后续会话都保持一致，下面哪种信息处理方式最合理？

- A. 短期状态保存行程，知识库检索规则，长期记忆保存高铁偏好
- B. 短期状态保存本次行程，长期记忆保存规则和高铁偏好
- C. 会话状态保存三类信息，结束时统一清除
- D. 长期记忆保存本次行程和高铁偏好，规则检索一次后长期保存

**参考答案：A**

**考点：** 当前任务状态应与跨会话偏好分离；企业报销规则应从可维护的权威知识源检索，避免保存过期规则。

### 单选 4：Decoder-only 模型的注意力掩码

**题目：** 在 decoder-only 语言模型的 teacher forcing 训练中，批次中的序列在右侧补 PAD，位置 `t` 的隐藏状态用于预测下一个真实 token，PAD 位置不计入损失。现比较两种注意力配置：配置 1 只屏蔽 PAD key，非 PAD token 之间可以相互注意；配置 2 同时使用 padding mask 和 causal mask，使位置 `t` 只能访问不晚于 `t` 的 token。训练中配置 1 的损失下降更快且更低，但逐 token 生成效果反而较差。以下判断最准确的是？

- A. 配置 1 使位置 `t` 在预测下一个 token 时读到后续 token，较低损失可能来自未来信息泄露；配置 2 才与自回归生成一致
- B. 配置 1 扩大了每个位置的有效上下文，较低训练损失表明模型利用了更多条件信息，逐 token 生成时仍可沿用这一训练关系
- C. 两种配置在有效 token 上的可见范围近似，指标差异更可能由 PAD 位置不计损失造成，应先修改损失掩码
- D. 配置 2 主要限制历史 token 参与注意力，训练时可用上下文减少，因此损失升高反映的是历史信息利用不足

**参考答案：A**

**考点：** 自回归训练必须阻止当前位置看到未来 token；仅有 padding mask 不等于 causal mask。

### 单选 5：Python 多继承与 `super()`

**题目：** 下面 Python 代码的运行结果为（ ）。

```python
class A:
    def __init__(self):
        print("A", end=" ")

class B(A):
    def __init__(self):
        super().__init__()
        print("B", end=" ")

class C(A):
    def __init__(self):
        super().__init__()
        print("C", end=" ")

class D(B, C):
    def __init__(self):
        super().__init__()
        print("D", end=" ")

d = D()
```

- A. A C B D
- B. A B C D
- C. A D
- D. A B D

**参考答案：A（A C B D）**

**考点：** `D` 的 MRO 是 `D → B → C → A → object`；初始化调用先向后进入 `A`，再按返回顺序打印 `C、B、D`。

### 不定项 1：缓解深度学习网络的长时间训练问题

**题目：** 以下哪些方法可以用于解决深度学习网络的长时间训练问题（ ）。

- A. 参数初始化技术
- B. 批标准化（Batch Normalization）技术
- C. 增加模型的深度
- D. 优化器调整

**参考答案：A、B、D**

**考点：** 合理初始化、归一化及优化器调整可能改善收敛速度与稳定性；增加深度通常不会直接缩短训练时间。

### 不定项 2：操作系统死锁

**题目：** 下列选项是有关死锁过程的一些描述，正确的有（ ）？

- A. 当计算机系统由于外界某些因素而发生故障时会出现死锁
- B. 当计算机系统中的资源数比进程数小很多时会出现死锁
- C. 一次分配所有资源的方法可能会造成进程“饥饿”
- D. 一次分配所有资源的方法实现了对死锁的预防

**参考答案：C、D**

**考点：** 死锁涉及特定资源占有及等待关系，并非资源较少或出现故障就必然发生；一次性请求所需全部资源可破坏“请求并保持”条件，但可能增加等待和饥饿风险。

### 不定项 3：Agent 信息生命周期治理

**题目：** 上线后的 Agent 出现三类问题：用户在多个会话中反复声明“优先用中文、回答简洁”，新会话仍经常恢复默认风格；产品价格更新后，Agent 仍引用旧版资料；排查日志只能看到检索片段，无法确认其来源文档和版本。为按信息生命周期治理这些问题，下列措施合理的是（ ）。

- A. 将当前会话状态整体转存为长期记忆，并在新会话中优先恢复，以减少偏好信息丢失
- B. 将用户明确确认且较稳定的表达偏好写入按用户隔离的长期记忆，并记录更新时间与覆盖规则
- C. 在检索结果和生成日志中记录文档标识、版本或时间戳，使回答能够追溯到知识来源
- D. 将价格等时效性较强的事实保留在外部知识库，检索时按生效时间或版本过滤，并设置更新与失效机制

**参考答案：B、C、D**

**考点：** 用户级持久偏好、检索可追溯性、时效知识版本治理；不应将整段会话无差别写入长期记忆。

### 不定项 4：LLM 在线推理的调度与 KV Cache

**题目：** 监控数据显示，采用连续批处理的在线推理服务在长 prompt 请求集中到达时，P95 首 token 时延上升，正在 decode 的请求单 token 时延也出现尖峰；提高最大活跃序列数后吞吐提升，但 KV Cache 接近显存上限并触发频繁抢占。若目标是在控制 KV Cache 峰值的同时缓解 prefill 与 decode 之间的资源干扰，下列措施及影响判断正确的是（ ）。

- A. 继续提高最大活跃序列数，可通过更大的并发批次摊薄每个请求的 KV Cache 占用，从而降低整体显存峰值
- B. 将长 prompt 的 prefill 分块，并限制每轮 token 预算，可减少其对 decode 调度的持续阻塞
- C. 扩大每轮 decode 批次规模会缩短各请求的逐 token 生成时间，并为新请求的 prefill 留出更多计算预算
- D. 按预计 KV 占用实施请求准入或延迟调度，可降低 OOM 风险，但延迟调度会使相关请求的首 token 时延上升

**参考答案：B、D**

**考点：** Chunked Prefill、Continuous Batching、Token Budget、KV Cache 容量与请求准入控制之间的吞吐/延迟权衡。

### 不定项 5：SFT 和 DPO 的训练数据与目标

**题目：** 在 LLM 后训练中，数据集 X 的每条样本包含一个用户指令和一条期望回答，数据集 Y 的每条样本包含同一指令下的一个优选回答和一个不被偏好的回答。关于使用 SFT 与 DPO 处理这两类数据的说法，哪些正确？

- A. DPO 通常利用 Y 中的偏好对，在不必显式训练奖励模型的前提下优化模型对回答的相对偏好
- B. SFT 通常以 X 中的示范回答为监督信号，直接优化模型对示范序列的条件概率
- C. DPO 仍以单条示范回答的监督交叉熵为核心目标，偏好回答只用于组织样本
- D. DPO 可通过偏好对直接获得预训练阶段所需的通用语言知识

**参考答案：A、B**

**考点：** SFT 的监督目标与 DPO 的成对偏好优化目标不同；DPO 不是通用预训练的替代品。

## 四、编程题（Python 3，ACM 模式）

### 编程 1：数轴机器人收集糖果

**题目描述：**

在一条数轴上有一个机器人，初始位于坐标 `0`。除此之外，坐标为 `i` 的点上有 `|i|` 颗糖果，其中 `|x|` 代表 `x` 的绝对值。

现在小强编写了一段长度为 `n` 且仅包含 `L` 和 `R` 的指令，其中 `L` 代表让机器人左移一格，`R` 代表让机器人右移一格。

当机器人第一次到达某个点时，他将获得这个点的所有糖果。现在这段指令将会循环 `k` 次，问机器人在指令结束后总共获得多少糖果。

**输入描述：**

- 第一行两个空格分隔的正整数 `n, k`，含义如题面所述。
- 第二行一个长度为 `n` 的字符串，只包含 `L` 和 `R`。
- `1 ≤ n, k ≤ 10^6`。
- 保证指令执行时机器人的坐标绝对值不会超过 `10^9`。

**输出描述：**

- 仅一行一个整数代表答案。

**示例 1：**

输入：

```text
3 2
RRR
```

输出：

```text
21
```

说明：机器人坐标依次变化为 `0 → 1 → 2 → 3 → 4 → 5 → 6`，共获得 `1 + 2 + 3 + 4 + 5 + 6 = 21` 颗糖果。

#### 考试中给出的 Python 完整代码

```python
n, k = map(int, input().split())
s = input().strip()

pos = 0
left = 0
right = 0

for c in s:
    if c == 'L':
        pos -= 1
    else:
        pos += 1

    left = min(left, pos)
    right = max(right, pos)

if pos > 0:
    right += (k - 1) * pos
elif pos < 0:
    left += (k - 1) * pos

if left >= 0:
    ans = (left + right) * (right - left + 1) // 2
elif right <= 0:
    ans = (-left - right) * (right - left + 1) // 2
else:
    ans = (-left) * (-left + 1) // 2
    ans += right * (right + 1) // 2

print(ans)
```

**思路摘要：**

- 机器人每步移动 1 格，因此走过的位置一定形成一个连续整数区间 `[left, right]`，重复到达的位置不会重复获得糖果。
- 遍历一次指令，求单轮轨迹的最左、最右坐标及单轮净位移 `pos`。
- 若单轮净位移为正，则后续循环使区间右端不断平移；若为负，则左端不断平移；若为 0，则循环不会扩大已访问区间。
- 最后通过等差数列公式求区间内所有整数绝对值之和。

**复杂度：** 时间 `O(n)`，额外空间 `O(1)`（不计输入字符串）。代码仅使用 Python 基础语法，无第三方库、无自定义函数。
