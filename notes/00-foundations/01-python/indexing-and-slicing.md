# 索引与切片：F01-01 课堂整理

> 这份笔记按照课堂讲解顺序整理，保留直观解释、代码示例、Tensor Shape 与错题原因，而不是只写结论。个人掌握记录见 [F 共享基础进度](../../../progress/FOUNDATIONS.md)。

## 1. 从 Python 容器开始

容器是管理多份数据的基本结构。算法代码中经常用 `list` 放序列、`tuple` 表示固定的 Shape、`dict` 放训练样本或配置、`set` 去重。

| 类型 | 例子 | 特点 | 工程场景 |
| --- | --- | --- | --- |
| `list` | `[1,2,3]` | 有序、可修改 | 一串动作或数据 |
| `tuple` | `(8,3,224,224)` | 有序、不可修改 | Tensor Shape |
| `dict` | `{"state": [0.1,0.2]}` | 键值映射 | Dataset 样本与 Batch |
| `set` | `{1,2,3}` | 元素唯一、无位置索引 | 去重 |

```python
a = [10, 20, 30]
a.append(40)          # 在列表末尾添加
a.pop()               # 删除并返回最后一项
len(a)                # 3
20 in a               # True

sample = {"image": [1, 2, 3], "state": [0.1, 0.2]}
sample["state"]        # [0.1, 0.2]
sample.get("depth")    # None；缺少 key 时不会报 KeyError
```

### 引用与复制

`b = a` 是把已有列表对象的引用交给 `b`，**不是复制内容**；`a.copy()` 才新建外层列表。要注意浅拷贝只复制外层：列表内若包含其他可变列表，其内部对象仍可能共享。

```python
a = [1, 2, 3]
b = a
c = a.copy()
b[0] = 99
print(a)             # [99, 2, 3]
print(c)             # [1, 2, 3]
```

这部分属于课堂导入，尚未专项测验，不把所有容器/拷贝知识直接标记为已掌握。

## 2. 一维索引：从 0 开始，也能倒着数

对于 `a = [10,20,30,40,50,60]`：

| 正索引 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 值 | 10 | 20 | 30 | 40 | 50 | 60 |
| 负索引 | -6 | -5 | -4 | -3 | -2 | -1 |

`a[0]` 是 `10`，`a[-1]` 是 `60`。**索引取得一项；切片选出一段。**

切片语法是：

```python
a[start:stop:step]
```

- `start`：开始索引，包含；
- `stop`：结束边界，**不包含**（左闭右开）；
- `step`：步长。`2` 表示每隔一项取一项，`-1` 表示倒序。

```python
a = [10, 20, 30, 40, 50, 60]
a[1:4]     # [20, 30, 40]
a[:3]      # [10, 20, 30]
a[3:]      # [40, 50, 60]
a[:]       # 所有元素的新列表（浅拷贝）
a[::2]     # [10, 30, 50]
a[::-1]    # [60, 50, 40, 30, 20, 10]
a[-3:]     # [40, 50, 60]
a[:-1]     # [10, 20, 30, 40, 50]
a[1]       # 20（单个整数）
a[1:2]     # [20]（长度为 1 的列表）
```

### 课末错题：`a[1:-1:2]` 为什么取不到 `60`？

`-1` 对应最后一项的**位置**（这里是正索引 5），但是写在 `stop` 位置时依然**不包含这个索引**。从 1 开始，按步长 2 前进，合法位置只有 1 和 3。

```python
a[1::2]      # [20, 40, 60]：终点省略
a[1:-1:2]    # [20, 40]：终点是索引 5，但不包含
```

变式复测：`[0,1,2,3,4,5,6,7][1:-2:2]`。长度 8 时 `-2` 对应正索引 6，取到的索引是 1、3、5，因此输出 `[1,3,5]`。**负索引改变的是位置的写法，不改变左闭右开的规则。**

## 3. 多维 Tensor：每一个逗号对应一个轴

普通嵌套列表可以写 `a[1][2]`；在 NumPy/PyTorch 里，Tensor 允许 `x[1,2]` 的多维索引。

```python
import torch
x = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])    # Shape [2,3]

x[1, 2]       # tensor(6)
x[0, :]       # tensor([1,2,3])；Shape [3]
x[:, 1]       # tensor([2,5])；Shape [2]
x[:, 1:2]     # tensor([[2],[5]])；Shape [2,1]
```

这里有一个特别重要的规律：

**整数索引通常会移除对应的轴；普通切片会保留这个轴，即使只保留一项。**

| 写法 | 解释 | 返回 Shape |
| --- | --- | --- |
| `x[0]` | 选第 0 行，移除行轴 | `[3]` |
| `x[:,0]` | 所有行 + 第 0 列，移除列轴 | `[2]` |
| `x[:,0:1]` | 所有行 + 切出第 0 列，保留列轴 | `[2,1]` |
| `x[:1,:]` | 切出第 0 行，保留行轴 | `[1,3]` |

## 4. 为什么具身模型一定要理解 Shape？

假设机器人有 3 个 RGB 摄像头，输入数据为 `images.shape = [8,3,3,224,224]`，约定五个轴是：

- `B=8`：Batch 中有 8 条数据。
- `V=3`：3 个相机视角（例如 head / left wrist / right wrist）。
- `C=3`：RGB 三通道。
- `H=W=224`：图像的高、宽。

```python
images = torch.randn(8, 3, 3, 224, 224) # [B,V,C,H,W]

images[0].shape                  # [3,3,224,224]，移除 Batch 轴
images[:,0].shape                # [8,3,224,224]，移除视角轴 V
images[:,0:1].shape              # [8,1,3,224,224]，保留 V
images[:,:2].shape               # [8,2,3,224,224]，前两路相机
images[:,1:2,:,:100,:].shape     # [8,1,3,100,224]
images[...,0].shape             # [8,3,3,224]，最后的宽度轴 W 被索引
```

`...` 是省略号，代表未显式列出的若干个完整轴。`images[...,0]` 选的是**最后一个维度 `W` 的第 0 个位置**，不是第 0 个相机。

因为 `V` 与 `C` 的数值都为 3，即使不小心交换这两个轴，Shape 的数字可能依旧一样，但语义完全错误。排查输入时需要同时写清 **[B,V,C,H,W]**，不能只看数字。

## 5. 普通列表切片与 Tensor 切片的内存差异

- 对 Python `list` 使用 `a[:]` 会创建一个新列表，但属于**浅拷贝**，嵌套的可变对象仍可能共享。
- PyTorch 的基础切片通常生成共享底层存储的 **view**；对 view 做原地修改可能改变原 Tensor。
- 若需要独立内存，可使用 `clone()`；高级索引常会生成新 Tensor。更细的 `reshape/view/permute/contiguous` 留到 F02。

这点在数据预处理、裁剪图像、以及修改动作张量时值得特别注意。

## 6. 复习速记

1. **切片左闭右开**，`stop=-1` 也不包含最后一项。
2. **整数索引消轴，切片保轴**：`x[:,0]` 与 `x[:,0:1]` 的 Shape 不一样。
3. **相同尺寸不代表相同轴**：尤其别混淆相机视角 `V` 和颜色通道 `C`。
4. Python 列表复制和 Tensor view 的内存行为不同。
