# ChatGPT 双项目配置

建议建立 **两个 ChatGPT Projects（项目）**，不是两个自定义 GPT：

| 名称 | 设置说明 | 进度记录 |
|---|---|---|
| 具身智能 · 基础与工程 | [EMBODIED_PROJECT_INSTRUCTIONS.md](EMBODIED_PROJECT_INSTRUCTIONS.md) | [具身进度](../progress/EMBODIED.md) |
| LLM / Agent · 从零到算法岗 | [LLM_AGENT_PROJECT_INSTRUCTIONS.md](LLM_AGENT_PROJECT_INSTRUCTIONS.md) | [LLM 进度](../progress/LLM_AGENT.md) |

共同前提：[SHARED_CONTEXT.md](SHARED_CONTEXT.md) 与 [LEARNING_RULES.md](../LEARNING_RULES.md)。两条项目共享同一份 [F 学习进度](../progress/FOUNDATIONS.md)，并分别记录 E、L 专项学习情况。

## 配置方法

1. ChatGPT 左侧栏创建新项目，分别命名。
2. 进入项目菜单（•••）→ Project settings，将对应 Instructions 文件中的内容粘贴到项目说明。
3. 在项目的第一条聊天贴出 GitHub 链接，并要求读取 README、对应路线地图和 progress 文件。
4. **项目记忆只用于聊天上下文**，不能代替 GitHub 文件。需要跨项目共享的笔记和进度必须写回仓库。
5. 对已有工作背景希望跨聊天参考，可选 **Default memory**；如果要求两个项目的聊天上下文完全隔离，选 **Project-only memory**，仍通过同一 GitHub 仓库共享文件。具体行为取决于账号/工作空间设置。

仓库当前为 public：不要向它上传私有凭据、未公开的面试/求职记录或其他未获授权的数据。
