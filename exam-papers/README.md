- **年份**按校招届别（不是考试年份）划分。
- 每份文档尽量注明企业、岗位、实际考试日期、材料来源和整理范围。
- 参考答案和样例代码应区分官方结论、个人推导与已验证结果；真题归档**不代表**课程已学习或掌握。
- 仅归档有权公开的个人整理内容；涉及保密义务的原卷、截图或其他敏感材料不公开上传。
