## 一、感知、几何与 SLAM

### 原题 1｜目标检测：减少误把背景识别为料箱

**题目**：移动机器人用相机检测货架上的料箱，模型输出检测框、类别和置信度。希望减少将背景纹理误识别为料箱的情况，下列后处理策略正确的是哪项？

- A. 结合置信度阈值、非极大值抑制和区域尺寸约束筛除低质量检测框。
- B. 扩大检测框边界并合并相邻结果，再将重叠区域统一标为同一料箱。
- C. 降低类别置信度阈值并保留更多候选框，让导航模块做空间过滤。
- D. 把相机画面按固定网格切块，按每块最大响应位置生成料箱中心点。

**参考答案：A**

**考点**：分类置信度阈值过滤假阳性；NMS 消除重复框；目标物体的合理尺寸和区域先验。注意置信度阈值提高可能降低召回率，不能只看准确率。

### 原题 2｜RGB-D：三维点坐标系统性偏向输送带一侧

**题目**：机械臂通过 RGB-D 相机估计料箱角点三维坐标，离线精度正常，但上线后抓取点整体偏向输送带一侧。若深度图质量稳定，最应优先排查哪项？

- A. 检测类别标签与料箱材质名称是否匹配，类别混淆会改变抓取高度。
- B. 相机到机械臂基座的外参标定是否发生偏移，坐标转换误差会形成系统性位置偏差。
- C. 深度相机帧率是否高于控制周期，帧率提升会改变末端执行器最大速度。
- D. 点云下采样体素尺寸是否小于相机像素间距，采样过密会放大输送带纹理。

**参考答案：B**

**考点**：手眼/外参标定，坐标系变换；系统性偏移优先考虑固定变换误差。实际排障还应区分传送带运动造成的时间延迟偏移。

### 原题 3｜点云：反光地面与托盘实例粘连

**题目**：在仓储场景中使用激光点云识别托盘腿，地面有金属反光条且托盘之间间距较小。如果聚类结果常将相邻托盘连接成一体，哪种改进最合理？

- A. 提高点云强度阈值并保留高反射点，让金属条参与后续聚类。
- B. 扩大聚类邻域半径并减少最小点数限制，以减少误分组。
- C. 先做地面与反光条候选剔除，再结合高度层和欧氏距离做分层聚类。
- D. 把单帧点云投影成二维占据栅格，选连通区域面积最大的目标。

**参考答案：C**

**考点**：地面分割、离群点/反光异常处理、Euclidean Clustering、三维结构先验。聚类半径扩大通常更容易把相近目标误合并。

### 原题 4｜行人跟踪：玻璃边缘干扰、角度分辨率低

**题目**：机器人在玻璃门附近跟踪周围行人。相机偶发漏检，激光点云受玻璃边缘干扰，毫米波雷达提供较稳定的径向速度但角度分辨率粗糙。要降低轨迹跳变，最合适的是哪项？

- A. 用雷达速度替换视觉位置观测，并按最近一次检测框中心更新轨迹。
- B. 以激光点云聚类为主观测，将玻璃边缘点按距离阈值合并入最近行人轨迹。
- C. 相机漏检时冻结目标位置，等下一帧检测框出现再恢复更新。
- D. 使用运动模型预测轨迹，结合雷达速度约束和视觉/点云观测门限做关联更新。

**参考答案：D**

**考点**：多目标跟踪、状态预测、量测关联、门控、EKF/UKF。不同传感器的量测精度和可观测量不一样，不能直接混用。

### 原题 5｜视觉 SLAM：ORB 特征的作用

**题目**：移动机器人在货架间行驶时，相邻相机帧视角变化不大，但轮速计在转弯处有轻微累计误差。视觉 SLAM 前端提取并匹配 ORB 特征主要起什么作用？

- A. 建立跨帧稳定的图像对应关系，为相机位姿估计提供观测约束。
- B. 利用更多图像纹理生成稠密货架地图，并将后端约束主要建立在稠密点云上。
- C. 用相邻帧整体亮度变化估计转弯速度，再修正轮速计误差。
- D. 在前端提前触发回环检测，让当前帧跳过与上一帧的特征匹配。

**参考答案：A**

**考点**：关键点、描述子、跨帧特征匹配、视觉里程计。ORB 提供对应观测，本身并不等于完成回环或全局优化。

### 原题 6｜视觉惯性融合：急转弯轨迹抖动

**题目**：机器人快速转弯时图像特征数量足够，但视觉惯性里程计轨迹出现明显抖动，IMU 标定参数正常。哪种原因判断最合理？

- A. 地图关键帧数量过多，后端图优化导致前端特征在转弯时丢失描述子。
- B. 相机与 IMU 时间戳存在偏差，视觉观测和惯性预积分对应到不同运动状态。
- C. 回环检测阈值偏低，系统在转弯处频繁误触发回环约束并扰动地图坐标。
- D. 图像分辨率高于 IMU 采样频率，像素数量变化会改变陀螺仪零偏方向。

**参考答案：B**

**考点**：时间同步、IMU 预积分、传感器外参与时间偏置。高速角运动会放大时间偏差的影响。

### 原题 7｜激光 SLAM：长走廊累计轨迹漂移

**题目**：移动机器人在长走廊使用激光 SLAM，前端里程计短时平滑，但累计轨迹逐渐弯向一侧，轮速计也有轻微偏差。什么更适合作为后端改进方向？

- A. 减少点云特征数量并提升前端帧率，让里程计结果更快进入建图线程。
- B. 增加墙面点角点权重，并把长直墙作为主要航向约束来源。
- C. 加入回环或全局一致性约束，并联合外部里程计信息对位姿图优化。
- D. 固定首帧和末帧位姿，再把中间帧按时间比例均匀插值到地图中。

**参考答案：C**

**考点**：前端里程计与后端图优化的分工、回环闭合、全局一致性与退化环境。长走廊还应关注几何退化和回环可检出性。

## 二、机器人学习与强化学习

### 原题 8｜奖励塑形：每前进一步奖励为正

**题目**：强化学习中设定“每前进一步都有正奖励”，却没有奖励接近目标。训练后最可能出现什么策略？

- A. 倾向尽快到达终点以缩短回合。
- B. 通过绕行或往返增加步数来累积奖励。
- C. 在起点保持静止以避免状态变化。
- D. 主动触发失败终止以提前结束回合。

**参考答案：B**

**考点**：奖励塑形、代理指标失效、reward hacking。设计稠密奖励时要明确进度、方向、终止条件和无效动作惩罚。

### 原题 9｜训练回报提高但成功率不变

**题目**：训练平均回报持续上升，但成功率不变；轨迹显示机器人常在目标附近徘徊，并持续获得小额奖励。最合理的结论是？

- A. 奖励函数与成功判定存在偏差，策略在优化局部奖励。
- B. 成功率统计窗口过长，尚未反映最新策略。
- C. 探索噪声过大，评估轨迹仍处于随机探索。
- D. 回报归一化尺度改变，使曲线数值上升。

**参考答案：A**

**考点**：训练奖励与任务成功率是两个不同指标；应检查完成事件、轨迹质量、超时/失败率和奖励各分量。

### 原题 10｜稀疏奖励与课程学习

**题目**：抓取任务奖励稀疏，随机探索几乎碰不到成功状态；环境支持从接近目标的位置开始训练，再逐步扩大初始范围。优先采用哪种调整？

- A. 继续提高随机动作噪声，等待偶然探索到完整成功轨迹。
- B. 采用课程学习（Curriculum Learning），逐步提高初始状态难度。
- C. 先用少量示范轨迹初始化策略，再保持原始困难初始状态分布。
- D. 加入基于距离的稠密奖励，并重新验证是否改变任务的最优策略。

**参考答案：B**

**考点**：课程学习和 reset distribution 设计。C、D 在其他前提下也可能有效，但题目明确给出逐步扩大初始化范围，直接对应 B。

## 三、机器人控制、状态估计与优化

### 原题 11｜Sim-to-Real：执行器响应延迟引起振荡

**题目**：摩擦随机化后的策略能适应多种真实地面；控制周期保持稳定时，只要将执行器响应比仿真延后约 40 ms，系统就持续振荡，调整接触刚度或观测噪声时现象不明显。哪项结论更合理？

- A. 接触刚度仍是主要未覆盖差异。
- B. 控制周期抖动仍是当前更关键的差异。
- C. 执行器响应延迟是当前更关键的域差异。
- D. 观测噪声幅值仍是主要差异。

**参考答案：C**

**考点**：执行器延迟、控制环相位滞后、仿真与真实硬件的延迟建模、控制频率与闭环稳定性。固定周期不等于低延迟。

### 原题 12｜执行器测试：线性动力学与非线性

**题目**：验证仿真执行器既能表现线性动态和负载敏感性，也能反映驱动非线性时，哪套测试方案最合适？

- A. 空载阶跃与扫频、静态保持电流、位置重复性。
- B. 阶跃与扫频、负载变化、饱和死区、正反向切换。
- C. 负载加减速、静态保持、温升变化、位置重复性。
- D. 空载阶跃、静态误差、编码器重复性、保持电流。

**参考答案：B**

**考点**：线性动态响应、负载相关参数、死区、饱和、迟滞与方向相关摩擦。仅测试空载无法覆盖负载非线性。

### 原题 16｜齐次位姿变换：旋转与平移顺序

**题目**：位姿变换约定为齐次矩阵左乘列向量。为了测试实现是否正确，以下哪种检查场景最能覆盖“旋转后平移”的顺序错误？

- A. 单位旋转配零平移，输入原点检查输出是否仍为原点。
- B. 使用非零旋转和非零平移，与手算结果比较。
- C. 只使用非零平移，输入沿坐标轴方向的单位向量。
- D. 只使用绕 z 轴旋转，输入旋转轴上的空间点。

**参考答案：B**

**考点**：齐次坐标、左乘约定、变换非交换性。对于列向量，`T p = R p + t`；`R(p+t)` 通常不等于 `Rp+t`。

### 原题 17｜相关量测的协方差融合

**题目**：定位模块融合两个协方差已知的位置估计，直接按相互独立假设计量融合协方差。数据链路检查发现两路估计共享同一里程计源，离线残差也明显正相关。继续采用独立假设的主要风险是什么？

- A. 融合均值会固定变成两个输入的算术平均，方差权重失效。
- B. 相关性主要影响融合均值，独立假设计算协方差仍然可靠。
- C. 融合协方差更可能被高估，后续观测权重会被压低。
- D. 融合协方差可能被低估，使系统对结果过度自信。

**参考答案：D**

**考点**：数据关联性、测量交叉协方差、信息重复计算、估计一致性。若忽略正相关，常产生过度乐观的协方差；工程上可考虑联合建模或 covariance intersection。

### 原题 18｜末端位置约束与大罚项

**题目**：轨迹优化通过一个很大的二次罚项逼近“终点必须到达指定位置”的等式约束。继续增大罚项权重后，终点误差虽减小，但线性系统条件数迅速恶化、迭代步长越来越小。现有方案应如何调整？

- A. 保持极大罚项权重，只靠缩短线搜索步长稳定迭代。
- B. 保留终点罚项，并在求解结束后把剩余误差均匀分配到整条轨迹。
- C. 改用显式等式约束或变量消元，避免继续增大罚项权重。
- D. 单独归一化终点残差，使其梯度尺度与其他项保持接近。

**参考答案：C**

**考点**：约束优化、二次罚函数、数值病态与线性系统条件数；还可比较 KKT 系统、增广拉格朗日方法及变量消元。

**题目**：Python 需要顺序处理一个 20 GB 二进制点云文件，处理函数每次接收不超过 4 MB 数据，且不能把全文件读入内存。哪种读取方式合适？

- B. 先用 `list(f)` 保存文件全部记录，再逐个弹出记录处理。

### 原题 19｜CAN 总线：终端反射与高速错误帧

**题目**：CAN 总线低速通信稳定，切换到 1 Mbit/s 后远端节点开始出现错误帧。断电测得 `CAN_H` 与 `CAN_L` 之间约 120 Ω，示波器在远端看到信号边沿反射，主干约 30 m。应优先排查并处理哪项？

- A. 在总线中部增加一个 120 Ω 终端，保留两端原配置。
- B. 降低收发器边沿速度并把采样点后移，暂不调整终端位置。
- C. 补齐缺失的远端 120 Ω 终端电阻。
- D. 在远端支路入口串联阻尼电阻，并拆除主控端现有终端电阻。

**参考答案：C**

**考点**：典型 CAN 主干两端各有一个 120 Ω 终端，断电并隔离其他干扰条件下总线两线间常测得约 60 Ω；测得约 120 Ω 可能只剩一个终端。**补充注意**：30 m、1 Mbit/s 还需检查位时序、线缆、支路长度和收发器规格，修复终端不保证单独解决全部问题。

### 原题 20｜增量编码器差分接口转 24 V 单端

**题目**：增量编码器输出 5 V 差分 A+/A− 脉冲，控制器只有一个 24 V 单端高速计数通道。直接接入 A+ 后低速时偶尔能计数，高速时大量丢脉冲；改造还要求保留差分信号的共模抑制能力。如何适配？

- A. 用差分接收器解码 A+/A−，再经过电平转换接入 24 V 高速计数输入。
- B. 把 A+ 和 A− 分别转换为 24 V 信号，各占用一个单端高速计数输入进行软件判决。
- C. 用双通道高速光耦分别隔离 A+ 和 A−，再由控制器软件合成脉冲。
- D. 使用高速比较器读取 A+ 相对信号地的电平，再转换到 24 V 计数输入。

**参考答案：A**

**考点**：差分信号接收、共模干扰抑制、RS-422 风格接收器、输入电平匹配。接收电路与输出级需要满足实际编码器和 PLC/计数器规格。

### 原题 13｜布尔掩码的原位修改

**题目**：执行以下代码，`a` 的值是什么？

```python
import numpy as np
a = np.array([1, 2, 3])
a[a > 1] *= 2
```

- A. `[1, 4, 6]`，满足条件的原数组元素被原地修改。
- B. `[1, 2, 3]`，布尔索引产生副本所以赋值不会生效。
- C. `[2, 4, 6]`，乘法作用于全部三个元素。
- D. `[1, 2, 6]`，只有最后一个满足条件的元素修改。

**参考答案：A**

**考点**：布尔掩码、索引赋值、NumPy 向量化；与 ReLU 梯度掩码、图像 mask 操作密切相关。注意读取 `b = a[mask]` 和执行 `a[mask] = ...` 的语义不同。

## 七、编程题 1｜NumPy 实现二层 MLP 一次训练更新

### 7.1 任务说明

在仅允许使用 `numpy` / `pandas` / `scikit-learn` 的条件下，实现一个两层全连接神经网络（MLP）的**一次前向传播、反向传播、梯度下降更新**，并输出更新前后损失及更新后参数和预测结果。

网络结构：`X → Linear1 → ReLU → Linear2 → Softmax`。

输入为一行 JSON，包括：

| 字段     | 形状/类型                | 含义                  |
| -------- | ------------------------ | --------------------- |
| `X`      | `N × d`                  | 一个 batch 的训练样本 |
| `y`      | 长度 `N`，整数 `0 … c−1` | 真实类别              |
| `W1`     | `d × h`                  | 第一层权重            |
| `b1`     | `h`                      | 第一层偏置            |
| `W2`     | `h × c`                  | 第二层权重            |
| `b2`     | `c`                      | 第二层偏置            |
| `lr`     | 浮点数                   | 学习率                |
| `lambda` | 浮点数                   | L2 正则系数           |

题目给出的核心公式：

\[
Z_1=XW_1+b_1,\qquad H=\max(Z_1,0),\qquad Z_2=HW_2+b_2.
\]

\[
P_{ik}=\frac{\exp(Z_{2,ik})}{\sum_j \exp(Z_{2,ij})},\qquad
L=-\frac{1}{N}\sum_{i=1}^N\log P_{i,y_i}
+\frac{\lambda}{2}\big(\|W_1\|_F^2+\|W_2\|_F^2\big).
\]

其中 Softmax 必须**按行减最大值**实现数值稳定；交叉熵必须做 batch 平均；L2 只作用于两层权重，不作用于偏置；ReLU 在零点导数取 0。

一次反向传播：

\[
G_2=\frac{P-Y}{N},\quad
\frac{\partial L}{\partial W_2}=H^TG_2+\lambda W_2,\quad
\frac{\partial L}{\partial b_2}=\sum_i G_{2,i}.
\]

\[
G_H=G_2W_2^T,\qquad G_1=G_H\odot \mathbf{1}[Z_1>0],
\]

\[
\frac{\partial L}{\partial W_1}=X^TG_1+\lambda W_1,\qquad
\frac{\partial L}{\partial b_1}=\sum_iG_{1,i}.
\]

所有参数使用更新**之前**算得的梯度，同时执行一次 SGD 更新：`θ_new = θ_old − lr × grad`。

输出仅为 JSON 对象，包含：

`loss_before`、`loss_after`、`pred`、`W1`、`b1`、`W2`、`b2`。所有浮点数按 `round(..., 6)` 保留六位小数；`pred` 是使用**更新后参数**对原 batch `X` 重新预测得到的类别列表。

### 7.3 参考实现（Python 3 / NumPy）

下面的代码已在本地用截图示例验证，结果与截图中的示例一致。代码用于复盘，**不代表已通过在线评测隐藏用例**。

```python
import sys
import json
import numpy as np

def solve(data):
    X = np.array(data['X'], dtype=float)
    y = np.array(data['y'], dtype=int)
    W1 = np.array(data['W1'], dtype=float)
    b1 = np.array(data['b1'], dtype=float)
    W2 = np.array(data['W2'], dtype=float)
    b2 = np.array(data['b2'], dtype=float)
    lr = float(data['lr'])
    lam = float(data['lambda'])
    n = X.shape[0]

    def calculate(W1, b1, W2, b2):
        Z1 = X @ W1 + b1
        H = np.maximum(Z1, 0)
        Z2 = H @ W2 + b2
        stable_Z2 = Z2 - Z2.max(axis=1, keepdims=True)
        e = np.exp(stable_Z2)
        sums = e.sum(axis=1, keepdims=True)
        P = e / sums
        # stable cross-entropy: - log softmax true-label
        loss_ce = -np.mean(stable_Z2[np.arange(n),y] - np.log(sums[:,0]))
        regularization = lam/2*(np.sum(W1**2)+np.sum(W2**2))
        return loss_ce + regularization, Z1, H, P
    loss_before, Z1, H, P = calculate(W1,b1,W2,b2)
    G2=P.copy()
    G2[np.arange(n),y] -= 1
    G2/=n
    dW2 = H.T @ G2 + lam*W2
    db2 = G2.sum(axis=0)
    G1 = (G2 @ W2.T) * (Z1>0)
    dW1 = X.T @ G1 + lam*W1
    db1 = G1.sum(axis=0)
    W1-=lr*dW1
    b1-=lr*db1
    W2-=lr*dW2
    b2-=lr*db2
    loss_after,_,_,P_new=calculate(W1,b1,W2,b2)
    result = {
        'loss_before':round(float(loss_before),6),
        'loss_after':round(float(loss_after),6),
        'pred':np.argmax(P_new,axis=1).tolist(),
        'W1':np.round(W1,6).tolist(),
        'b1':np.round(b1,6).tolist(),
        'W2':np.round(W2,6).tolist(),
        'b2':np.round(b2,6).tolist()
    }
    return result

if __name__=='__main__':
    print(json.dumps(solve(json.loads(sys.stdin.read())),separators=(',',':')))
```
